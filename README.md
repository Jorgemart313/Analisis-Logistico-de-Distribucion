Análisis Logístico de Distribución

Descripción
Este proyecto tiene como objetivo analizar datos de distribución logística para identificar patrones, evaluar costos y apoyar la toma de decisiones estratégicas en la optimización del sistema de distribución.
El análisis se enfoca en el crecimiento de la demanda y los desafíos asociados a la expansión operativa, utilizando herramientas de análisis de datos y visualización.

Objetivos
Limpiar y preparar los datos para su análisis.
Realizar un análisis exploratorio (EDA).
Identificar patrones de distribución y comportamiento de la demanda.
Evaluar posibles mejoras en la eficiencia logística.
Generar visualizaciones para facilitar la toma de decisiones.

Tecnologías utilizadas
-Python
-Pandas
-NumPy
-Matplotlib / Seaborn
-Power BI
-Google Colab / Jupyter Notebook
